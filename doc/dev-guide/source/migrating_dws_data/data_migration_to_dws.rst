Data Migration to DWS
=====================

You can import data from different sources to DWS. The features of each method are listed in :ref:`Table 1 <en-us_topic_0000001764650196__en-us_topic_0000001233681743_en-us_topic_0000001082926999_en-us_topic_0140501319_en-us_topic_0145255637_table10273436143718>`. You can select a method as required.

.. note::

   -  OBS, DLI, and MRS are cloud services.
   -  GDS, and **gs_restore**, and **gs_dump** are internal tools.
