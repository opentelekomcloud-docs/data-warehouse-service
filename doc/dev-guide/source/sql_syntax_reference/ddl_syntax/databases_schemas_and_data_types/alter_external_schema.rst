ALTER EXTERNAL SCHEMA
=====================

Function
--------

**ALTER EXTERNAL SCHEMA** modifies the attributes of an external schema. This syntax is supported only by clusters of version 8.3.0 or later.

Syntax
------

Modify an external schema based on the specified name.

::

   ALTER EXTERNAL SCHEMA schema_name
       WITH [ SOURCE source_name ]
            [ DATABASE 'database_name' ]
            [ SERVER server_name ]
            [ CATALOG 'catalog_name' ]
            [ OPTIONS ( { option_name ' value ' } [, ...] ) ]
            [ METAADDRESS 'address']
            [ CONFIGURATION 'confpath'];

Parameter Description
---------------------

.. table:: **Table 1** ALTER EXTERNAL SCHEMA parameters

   +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | Parameter             | Description                                                                                                                                                                                                             | Value Range                                                                                                                                                   |
   +=======================+=========================================================================================================================================================================================================================+===============================================================================================================================================================+
   | schema_name           | Specifies the name of the external schema to be modified.                                                                                                                                                               | Name of an existing external schema.                                                                                                                          |
   +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | SOURCE                | Specifies the type of the external metadata storage engine.                                                                                                                                                             | Currently, source_type can only be set to **dli**, **lakeformation**, or **hive**.                                                                            |
   +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | DATABASE              | Specifies the database to be accessed by the external schema.                                                                                                                                                           | ``-``                                                                                                                                                         |
   +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | SERVER                | You can associate an external schema with a foreign server to access external data.                                                                                                                                     | An existing foreign server whose type is **lf**, **obs**, **dli**, or **hdfs**.                                                                               |
   +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | CATALOG               | Specifies the catalog to be accessed in Lakeformation.                                                                                                                                                                  | ``-``                                                                                                                                                         |
   +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | OPTIONS               | Specifies parameters of foreign table data. This is supported only by 8.3.0 and later versions.                                                                                                                         | **dli_project_id**: project ID of DLI.    | METAADDRESS           | Specifies the address of the Hive Metastore communication interface.    +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | CONFIGURATION         | Specifies the path for storing Hive Metastore configuration files. This parameter is supported only by clusters of version 9.1.0 or later.                                                                              | ``-``                                                                                                                                                         |
   |                       |                                                                                                                                                                                                                         |                                                                                                                                                               |
   |                       | If objects in the schema on the current search path are with the same name, specify the schemas different objects are in. You can run the **SHOW SEARCH_PATH** command to check the schemas on the current search path. |                                                                                                                                                               |
   +-----------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------+

Examples
--------

Prerequisites:

#. Create servers named **lf_server** and **my_server** by referring to "Managing LakeFormation Data Sources" in the *Data Warehouse Service User Guide*.

#. Create an external schema named **ex1**.

   ::

      CREATE EXTERNAL SCHEMA ex1
          WITH SOURCE lakeformation
               DATABASE 'demo'
               SERVER lf_server
               CATALOG 'hive';

Modify the database and **FOREIGN SERVER** corresponding to the **EXTERNAL SCHEMA** whose name is **ex1**.

::

   ALTER EXTERNAL SCHEMA ex1
       WITH DATABASE 'demo'
            SERVER my_server;
